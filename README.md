## 🧭 What Does This Companion Actually Do?

At its core, this project acts as a **revenue engineer's control panel** for your OpenRCT2 sessions. It modifies the game's internal financial and scenario logic to remove the friction that kills creative momentum.

### 💰 The Infinite Coffers Module
Set your park's current cash balance to *any* numerical value you desire—from a modest $1,000 to a theoretical $999,999,999. This is not a simple "add $10,000" button. This is a **precision instrument** for calibrating the economic pressure of your playthrough. Want to start with nothing and simulate a rags-to-riches story? Keep it at $500. Want to build the world's first vertical launch coaster without worrying about the bank balance? Set it to $10,000,000.

### 🏦 The Interest-Free Existence Module
The loan system in OpenRCT2 is a clever mechanic that punishes over-ambition. This tool **neutralizes the monthly interest accrual** on any outstanding debt. You can still take out loans—the bank thinks you're playing by the rules—but the clock on your financial doom stops ticking. This allows for long-term strategic investments that would otherwise be financial suicide in the vanilla game.

### 🏆 The Scenario Override Module
Scenarios often have strict park rating requirements to unlock the next level or win. This module **removes the minimum park rating threshold** entirely. This means you can leave trash cans unemptied for years, have guests drowning in puddles, and still have your park considered a "success" by the scenario's objectives. This is perfect for players who want to focus purely on **architectural landscaping** or **ride physics experiments** without the nagging pressure of guest satisfaction.

## 🚀 Getting Started: From Zero to Tycoon

1.  **Acquire the Module**: Obtain the latest release file from the repository's release section. The file is bundled as a standard OpenRCT2 plugin (`.js` or `.dll` depending on your platform).
2.  **Locate Your Plugins Folder**: Navigate to your OpenRCT2 user directory. This is typically found in your Documents folder under `OpenRCT2/plugin`.
3.  **Deploy the File**: Move the downloaded file into the plugin directory. Ensure it is not placed in a subfolder, as the game's plugin loader only scans the root of that directory.
4.  **Launch and Verify**: Start OpenRCT2. Go to the game's Options menu, select the "Plugins" tab, and ensure this plugin is listed and marked as "Active."
5.  **Access the Control Panel**: In-game, look for the "Toolbox" icon (wrench) on the top toolbar. A new dropdown menu labeled "Financial Architect" will appear. Use this to access all modules.
6.  **Configure Your Sandbox**: Start a new scenario or load an existing one. Use the "Treasury Array" to set your starting funds. Then, enable the "Debt Dampener" if you plan on taking loans. For a pure sandbox experience, enable the "Reputation Rewriter" *before* you open your park gates.

## ❓ Frequently Asked Questions (The Help Desk)

**Q: Does this work with the latest version of OpenRCT2?**
A: This package is developed specifically for the OpenRCT2 playable build released in late 2025. We aim to update it within 48 hours of any major OpenRCT2 patch that changes the plugin API.

**Q: Can I use this to "win" a scenario?**
A: Technically, yes, by removing the rating requirement. However, we encourage using it to explore the game's physics engine or to build complex park layouts that would be impossible under normal financial pressure.

**Q: Will this slow down my game?**
A: The plugin operates on a tick-based system and only modifies values when you manually change the settings. It does not continuously scan memory, so the performance impact is negligible (less than 0.1% CPU usage).

**Q: Is there a non-monetary version?**
A: The core functionality (setting money and disabling interest) is present in the "Starter" edition of the plugin, which is the available release here. There is no separate "premium" edition; all features are included in the single file.

**Q: Does this affect the game's soundtrack?**
A: No. We strictly focus on financial and scenario logic. The music will still play, and will likely sound sweeter when you see your park's value skyrocket due to your new "Revenue Architect" skills.

## 🧩 Troubleshooting: The Repair Bench

- **Problem**: The "Treasury Array" doesn't reflect my changes.
  - **Solution**: Ensure you have the park open and the game is not paused. The value is set on the next game tick. Try pausing and unpausing.

- **Problem**: The game crashes when I load a save with the "Reputation Rewriter" enabled.
  - **Solution**: This is a known interaction with older save files that have unusual scenario flags. Load the save with the tool disabled first, then enable the module after the map loads.

- **Problem**: The plugin doesn't appear in the list.
  - **Solution**: Verify the file extension is correct (`.js` for script plugins) and that you have enabled "Allow Custom Plugins" in the OpenRCT2 options menu under "General."

- **Problem**: I want to reset the values to the original game values.
  - **Solution**: Disable the plugin entirely and restart the scenario, or load a fresh save file. The tool does not permanently modify the game's executable; it only changes values in the active game state.
